Плановый бюджет в 55% — консервативное допущение, а не измеренное соглашение об уровне обслуживания (SLA). Нагрузочный тест не включал промышленный обратный прокси-сервер, внешнюю систему мониторинга и реальные браузерные WebSocket-клиенты.

## Расчёт команды и экономики

Состав команды для пилотного проекта без интеграции с OPC/SCADA, точного физического моделирования и промышленной сертификации:

- Средняя загрузка обязательных ролей: около 7,3 FTE.
- Опциональные специалисты по ML/LLM: 0,5–1,0 FTE.
- Продолжительность: 4–6 месяцев.
- Плановая трудоёмкость: 30–45 человеко-месяцев; подготовка опционального ML/LLM к промышленной эксплуатации добавит примерно 4–8 человеко-месяцев.

```text
CAPEX_разработки = сумма(FTE_i * месяцы * полная_месячная_стоимость_роли_i)
годовой_OPEX = инфраструктура + резервное_копирование_и_мониторинг + поддержка + обновление_контента + безопасность_и_аудит + инференс
стоимость_сессии = (годовой_OPEX + амортизированный_CAPEX) / число_завершённых_сессий_в_год
годовой_эффект = сэкономленные_часы_инструктора + сэкономленное_время_обучения + подтверждённое_снижение_риска
срок_окупаемости_в_месяцах = CAPEX_разработки / (месячный_эффект - месячный_OPEX)
```

Рыночные зарплаты, налоги, облачные тарифы, цены оборудования и стоимость предотвращённых инцидентов не учитывались, поскольку не были указаны география, валюта, схема закупки, SLA и внутренние ставки.
